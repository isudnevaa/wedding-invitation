# 🔧 Подробная инструкция: Шаги 3 и 4

## 📖 Шаг 3: Опубликуйте как Web App (очень подробно)

### 3.1 Откройте Apps Script

В Google Таблице:
1. В верхнем меню найдите **Extensions** (Расширения)
2. Нажмите на **Apps Script**
3. Откроется новая вкладка с редактором кода

---

### 3.2 Вставьте код

1. В редакторе удалите весь код который там есть по умолчанию (функция `myFunction()`)
2. Скопируйте код из файла `Code.js.txt`
3. Вставьте в редактор

**Должно получиться:**
```javascript
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    // ... весь код
}
```

---

### 3.3 Вставьте ваш email

В коде найдите строку 27:
```javascript
var recipient = 'vash@email.com'; // ← ВАШ EMAIL
```

Замените `vash@email.com` на ваш реальный email, например:
```javascript
var recipient =ivan@gmail.com'; // ← ВАШ EMAIL
```

---

### 3.4 Сохраните код

1. Нажмите **Ctrl+S** или иконку 💾 (Save) вверху
2. Введите название проекта: "RSVP Script"
3. Нажмите **OK**

---

### 3.5 Начните развертывание (Deploy)

1. В верхнем меню найдите кнопку **Deploy** (Развернуть)
2. Нажмите на неё
3. Выберите **New deployment** (Новое развертывание)

---

### 3.6 Настройте deployment

Откроется окно настройки:

**1️⃣ Выберите тип:**
- Нажмите на кнопку рядом с "Select type"
- Выберите **Web app** (Веб-приложение)

**2️⃣ Заполните данные:**

| Поле | Значение | Пояснение |
|------|----------|-----------|
| **Description** (Описание) | `RSVP API` | Название для вас |
| **Execute as** (Выполнять от имени) | `Me (ваш@email.com)` | Важно! От вашего имени |
| **Who has access** (Кто имеет доступ) | `Anyone` (Любой) | Важно! Иначе не будет работать |

**3️⃣ Важные настройки:**

- ✅ **Execute as: Me** — скрипт будет работать от вашего имени (доступ к таблице и email)
- ✅ **Who has access: Anyone** — гости смогут отправлять формы без входа в Google

---

### 3.7 Разверните

1. Нажмите кнопку **Deploy** (Развернуть)
2. Появится окно с предупреждением — нажмите **Authorize access** (Авторизовать доступ)

---

### 3.8 Авторизация

**В первый раз нужно авторизовать скрипт:**

1. Откроется окно Google
2. Выберите ваш Google аккаунт
3. Появится предупреждение "Google hasn't verified this app" (Google не проверил это приложение)
4. Нажмите **Advanced** (Дополнительно)
5. Прокрутите вниз и нажмите **Go to RSVP Script (unsafe)**
6. Нажмите **Allow** (Разрешить)

> ⚠️ Это нормально — вы авторизуете свой собственный скрипт

---

### 3.9 Получите URL

После успешного развертывания:

Откроется окно с информацией о deployment. Внизу будет надпись:

```
Web app
https://script.google.com/macros/s/......../exec
```

**Скопируйте этот URL!** Он понадобится на следующем шаге.

---

## 📖 Шаг 4: Получите URL и вставьте в проект

### 4.1 Скопируйте URL

Из окна deployment:

1. Найдите строку **Web app**
2. Нажмите на иконку 📋 (копировать) рядом с URL
3. Или выделите URL и скопируйте (Ctrl+C)

**URL выглядит так:**
```
https://script.google.com/macros/s/AKfycbz......../exec
```

> ❌ НЕ копируйте URL с `/dev` на конце — нужен `/exec`!

---

### 4.2 Откройте файл проекта

На компьютере откройте файл:
```
C:\Users\isudneva\wedding-invitation\js\rsvp.js
```

---

### 4.3 Найдите нужную строку

Используйте поиск (Ctrl+F) и введите:
```javascript
submitUrl
```

Найдите строку:
```javascript
submitUrl: null, // ← Вставьте сюда URL: https://script.google.com/macros/s/.../exec
```

---

### 4.4 Вставьте URL

Замените `null` на ваш URL, например:

**Было:**
```javascript
submitUrl: null, // ← Вставьте сюда URL
```

**Стало:**
```javascript
submitUrl: 'https://script.google.com/macros/s/AKfycbxYz...8Gw/exec',
```

> ✅ Важно: URL должен быть в кавычках!

---

### 4.5 Сохраните файл

1. Нажмите **Ctrl+S**
2. Закройте файл

---

## 🆘 Если не работает

### Ошибка 404 при отправке

**Проблема:** Неверный URL

**Решение:**
1. Проверьте что URL заканчивается на `/exec`, НЕ `/dev`
2. Пересоздайте deployment (шаг 3)

---

### Ошибка "Unauthorized"

**Проблема:** Неверные настройки доступа

**Решение:**
1. Откройте Apps Script
2. Deploy → Manage deployments
3. Нажмите на редактирование (карандаш)
4. Проверьте что "Who has access" = "Anyone"

---

### Email не приходит

**Проблема:** Попал в спам или неверный email

**Решение:**
1. Проверьте папку Спам
2. Откройте код и проверьте строку `var recipient = '...'`
3. Убедитесь что email правильный

---

### Ошибка в таблице

**Проблема:** Неверный формат данных

**Решение:**
1. Проверьте консоль браузера (F12) при отправке
2. Посмотрите какие данные отправляются
3. Откройте Apps Script → Executions (выполнения) для логов
