# 📱 Как отправить приглашение в Telegram

Есть **3 способа** отправить цифровое приглашение в Telegram:

---

## ✅ Способ 1: Telegram Mini App (Лучший!)

Приглашение открывается **как внутри приложений Telegram** с плавными переходами.

### Шаги:

1. **Создайте Telegram бота**
   - Откройте [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте `/newbot`
   - Назовите бота (например: `wedding_d_i_bot`)
   - Получите токен (сохраните его!)

2. **Настройте Web App**
   - Отправьте `/newapp` BotFather'у
   - Выберите вашего бота
   - Введите URL вашего приглашения (см. "Где разместить")

3. **Создайте кнопку**
   - Отправьте `/mybots` → выберите бота → **Menu Button**
   - Или добавьте кнопку в чате с ботом

4. **Отправляйте гостям**
   - Поделитесь ссылкой на бота: `t.me/ваш_бот`
   - Гости открывают → нажимают меню → видят приглашение

### Плюсы:
- ✅ Открывается внутри Telegram
- ✅ Работает как нативное приложение
- ✅ Плавные анимации
- ✅ Доступ к профилю пользователя (если нужно)

---

## ✅ Способ 2: Прямая ссылка (Самый простой)

Приглашение открывается **в браузере смартфона**, но выглядит как приложение благодаря PWA.

### Шаги:

1. **Разместите приглашение онлайн** (см. ниже "Где разместить")
2. **Отправьте ссылку гостям** в Telegram

   ```
   https://your-link.com
   ```

3. **Гости открывают** и могут добавить на главный экран:
   - iOS: Safari → Поделиться → "На экран Домой"
   - Android: Chrome → Меню → "Установить приложение"

### Плюсы:
- ✅ Не требует создания бота
- ✅ Быстро настроить
- ✅ Можно установить как приложение
- ✅ Работает оффлайн после первого посещения

---

## ✅ Способ 3: Telegram Web App (Кнопка в чате)

Добавьте кнопку в **личный чат** с гостем.

### Шаги:

1. **Создайте бота** (как в Способе 1)
2. **Настройте Web App** (как в Способе 1)
3. **Используйте Deep Link** для отправки:

   ```
   https://t.me/ваш_бот?startapp
   ```

### Плюсы:
- ✅ Быстрая отправка каждому гостю
- ✅ Персонализированные ссылки

## 📲 Как будет выглядеть для гостей?

### Telegram Mini App:
```
Гость открывает Telegram
     ↓
Находит бота / переходит по ссылке
     ↓
Нажимает кнопку "Открыть"
     ↓
Приглашение открывается как встроенное приложение
     ↓
Плавные переходы, сохраняет состояние
```

### PWA (Прямая ссылка):
```
Гость переходит по ссылке
     ↓
Открывается в браузере
     ↓
Видит предложение "Установить"
     ↓
При установке — иконка на главном экране
     ↓
Открывается как отдельное приложение
```

**Почему:**
- ❌ Нет необходимости создавать бота
- ✅ Быстро настроить

- ✅ Гости могут установить как приложение

## 💡 Дополнительные советы

1. **Создайте короткую ссылку**
   - Используйте [bit.ly](https://bit.ly) или [goo.gl](https://goo.gl)
   - Пример: `bit.ly/dima-ira-wedding`

2. **Добавьте QR-код**
   - Сгенерируйте на [qr-code-generator.com](https://qr-code-generator.com)
   - Распечатайте на бумажных приглашениях

3. **Персонализируйте**
   - Добавьте параметр `?guest=Имя` для каждого гостя
   - Пример: `your-site.com/?guest=Иван`

4. **Создайте несколько версий**
   - Для семьи
   - Для друзей
   - Для коллег

## 🔧 Настройка для Telegram Mini App

Если выбрали **Способ 1**, добавьте в `script.js`:

```javascript
// Telegram WebApp API
if (window.Telegram?.WebApp) {
    const tg = window.Telegram.WebApp;

    // Расширяем на весь экран
    tg.expand();

    // Устанавливаем цвет темы
    tg.setHeaderColor('#f5f0e8');
    tg.setBackgroundColor('#f5f0e8');

    // Кнопка "Назад" в Telegram
    tg.BackButton.onClick(() => {
        // Ваш код для возврата
    });
    tg.BackButton.show();
}
```
